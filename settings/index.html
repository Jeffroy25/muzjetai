Keys to add in Netlify

Only add the providers you want. Openverse and Wikimedia work without keys.

GEMINI_API_KEY=your_existing_gemini_key PIXABAY_API_KEY=your_pixabay_key PEXELS_API_KEY=your_pexels_key UNSPLASH_ACCESS_KEY=your_unsplash_access_key MEDIA_PROVIDER_ORDER=pixabay,pexels,openverse,wikimedia,unsplash

Never paste secret keys into this page or into frontend source code. Use Netlify → Site configuration → Environment variables.
